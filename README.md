# نَبْتَة | NABTA Smart Agriculture

منصة عربية تجريبية للزراعة الذكية لمتابعة الحقول والمحاصيل ومؤشرات التربة والطقس.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## التقنيات

- Next.js App Router + TypeScript
- React
- React Leaflet + OpenStreetMap
- Lucide Icons
- CSS responsive مع دعم RTL

## الموجود في النسخة الأولية

- لوحة تحكم عربية متجاوبة.
- خريطة تفاعلية بثلاث قطع زراعية تجريبية.
- اختيار الحقل وعرض بياناته.
- إضافة حقول وتصدير بيانات CSV.
- واجهة رفع صورة أو فتح الكاميرا على الأجهزة المدعومة.
- واجهة محادثة أولية لمساعد نَبْتَة.

## ملاحظة مهمة عن البيانات والذكاء الاصطناعي

الحقول والأرقام والطقس في هذه النسخة بيانات توضيحية وليست قراءات حقيقية من حساسات. واجهة رفع الصور والمحادثة جاهزتان للتكامل، لكن لا يوجد حالياً نموذج تشخيص نباتات أو مزود ذكاء اصطناعي متصل. يلزم إعداد خدمة طقس ومصدر بيانات جغرافية وربط نموذج رؤية حاسوبية ومساعد لغوي قبل استخدامها لاتخاذ قرارات زراعية فعلية.

## خارطة الطريق

1. ربط تشخيص أمراض النباتات بنموذج موثوق مع إظهار درجة الثقة والمراجع.
2. إضافة قاعدة بيانات ومصادقة للمستخدمين والمزارع.
3. ربط الطقس بمصدر مباشر حسب إحداثيات الحقل.
4. دعم إدخال قراءات حساسات التربة وIoT.
5. إضافة رسم حدود الحقول يدوياً أو استيراد GeoJSON/KML.
