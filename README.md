# نَبْتَة | NABTA Smart Agriculture

منصة ويب عربية تجريبية للزراعة الذكية لمتابعة الحقول والمحاصيل وقراءة مؤشرات الغطاء النباتي من صور الأقمار الصناعية.

## التشغيل محليًا

```bash
npm install
Copy-Item .env.example .env.local
npm run dev
```

افتح http://localhost:3000

## التقنيات

- Next.js App Router وTypeScript
- React وReact Leaflet وLeaflet
- Esri World Imagery لطبقة صور الأقمار الصناعية
- OpenStreetMap لخريطة الشوارع وبيانات حدود الأراضي عبر Overpass API
- Copernicus Data Space Ecosystem Sentinel Hub Statistical API
- Sentinel-2 L2A وNDVI
- Lucide Icons
- واجهة عربية RTL وتصميم متجاوب

## إعداد تحليل Sentinel-2 / NDVI

1. أنشئ حسابًا في [Copernicus Data Space Ecosystem](https://dataspace.copernicus.eu/).
2. من إعدادات الحساب، أنشئ OAuth Client من قسم OAuth clients.
3. انسخ Client ID وClient Secret واحفظهما في ملف `.env.local` في جذر المشروع:

```env
CDSE_CLIENT_ID=ضع_client_id_هنا
CDSE_CLIENT_SECRET=ضع_client_secret_هنا
```

4. أعد تشغيل خادم Next.js بعد حفظ الملف.

**لا تضع Client Secret في كود الواجهة أو في GitHub أو في محادثة عامة.** ملف `.env.local` مستثنى من Git بواسطة `.gitignore`. يتم استدعاء Copernicus من Route خادمي، وليس من المتصفح.

## ما الذي يفعله تحليل NDVI؟

- يرسل حدود الحقل كـ GeoJSON إلى Sentinel Hub Statistical API.
- يستخدم مجموعة Sentinel-2 L2A ونطاقي الأحمر B04 وتحت الأحمر القريب B08.
- يحسب NDVI = (B08 - B04) / (B08 + B04).
- يستبعد بكسلات المياه والظلال السحابية والغيوم والسحب الرقيقة والثلوج، بالإضافة إلى البكسلات غير الصالحة.
- يجمع الإحصائيات على فترات 10 أيام خلال نافذة زمنية تقارب 90 يومًا وتنتهي قبل عدة أيام لتقليل احتمال طلب مشاهد لم تُنشر بعد.
- يعرض المتوسط والتغير عن الفترة السابقة ونسبة البكسلات الصالحة، مع توضيح مصدر البيانات ودقتها المكانية.
- يوفر `/api/ndvi/map` صورة NDVI ملونة وشفافة للحقل، باستخدام Process API، ويمكن إظهارها كطبقة فوق الخريطة عبر زر «عرض طبقة NDVI».
- تتدرج ألوان طبقة الخريطة من البني/الأصفر إلى الأخضر حسب قيمة NDVI، مع إخفاء البيكسلات خارج الحقل والغيوم والظلال والمياه.

## الوظائف الأخرى في النموذج

- لوحة تحكم عربية متجاوبة.
- التبديل بين صور الأقمار الصناعية وخريطة الشوارع.
- اقتراح حدود زراعية مسجلة في OpenStreetMap داخل نطاق الخريطة الحالي.
- رسم حدود الحقل يدويًا وحساب مساحة تقريبية بالفدان.
- حفظ الحقول وحدودها في Local Storage على المتصفح الحالي.
- تصدير سجل الحقول إلى CSV.
- واجهة أولية لرفع صورة النبات أو فتح الكاميرا ومساعد محادثة تجريبي.

## حدود الدقة والتفسير

- الحقول الافتراضية وحدودها وقياساتها بيانات توضيحية، وليست مزارع موثقة.
- الحقول المضافة تحفظ محليًا على المتصفح فقط؛ لا توجد قاعدة بيانات أو مزامنة بين الأجهزة حتى الآن.
- مساحة الحقل المحسوبة تقريبية وليست قياسًا مساحيًا معتمدًا.
- «اكتشف حقول المنطقة» يبحث عن حدود سبق رسمها في OpenStreetMap؛ لا يستخرج الحدود آليًا من صورة القمر الصناعي.
- NDVI مؤشر للغطاء النباتي وليس تشخيصًا للأمراض ولا قياسًا مباشرًا للإنتاجية. ألوان الطبقة تمثل قيم المؤشر داخل الحقل ولا تعني تصنيفًا طبيًا لصحة النبات. تتأثر القراءة بنوع المحصول ومرحلة النمو والتربة والري والظروف الجوية.
- دقة Sentinel-2 المستخدمة هنا 10 أمتار؛ قد لا تكون مناسبة للقطع الصغيرة جدًا أو لتقييم صفوف النباتات الفردية.
- نسبة التغطية الصالحة في الإحصائيات تعكس البكسلات التي اجتازت أقنعة الصلاحية، ولا تضمن وحدها جودة زراعية كاملة.
- لا توجد بعد قراءات حقيقية من حساسات التربة أو الطقس، وتشخيص صور النباتات والمساعد الذكي غير متصلين بنموذج AI فعلي.

## مصادر البيانات والإسناد

- صور الأقمار الصناعية والتحليل: [Copernicus Data Space Ecosystem – Sentinel Hub](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Overview/Authentication.html).
- خريطة الشوارع وبيانات الحقول: [OpenStreetMap](https://www.openstreetmap.org/copyright) وفق ODbL.
- استعلام الحدود المسجلة: Overpass API؛ وهي خدمة عامة مشتركة يجب استخدامها بطلبات صغيرة ومسؤولة.
- طبقة صور Esri تعرض الإسناد المطلوب داخل الخريطة؛ راجع شروط Esri قبل الإطلاق العام أو الاستخدام التجاري.

## خارطة الطريق

1. قاعدة بيانات ومصادقة للمستخدمين والمزارع.
2. ربط الطقس بموقع الحقل ومصدر مباشر.
3. تحسين عرض NDVI كطبقة لونية على الخريطة مع تخزين سجل التحليلات.
4. نموذج رؤية حاسوبية لتشخيص أمراض النباتات مع درجة ثقة وتوثيق البيانات.
5. مساعد زراعي متصل ببيانات الحقل ومراجع موثوقة.
6. قراءات حساسات التربة وIoT.
