# نَبْتَة | NABTA Smart Agriculture

منصة ويب عربية تجريبية للزراعة الذكية تساعد على تنظيم بيانات الحقول وعرضها على خريطة تفاعلية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## التقنيات

- Next.js App Router وTypeScript
- React وReact Leaflet وLeaflet
- Esri World Imagery لطبقة صور الأقمار الصناعية
- OpenStreetMap لخريطة الشوارع وبيانات حدود الأراضي الزراعية عبر Overpass API
- Lucide Icons
- واجهة عربية RTL وتصميم متجاوب

## الوظائف الموجودة في النموذج

- لوحة تحكم عربية متجاوبة.
- التبديل بين صور الأقمار الصناعية وخريطة الشوارع.
- اقتراح حدود زراعية موثقة في OpenStreetMap داخل نطاق الخريطة الحالي.
- معاينة المضلع المقترح واختيار حد واحد ثم إضافته إلى قائمة الحقول.
- رسم حدود قطعة أرض يدويًا بالنقر على الخريطة.
- حساب تقريبي لمساحة المضلع وتحويلها إلى فدان.
- حفظ الحقول وحدودها في Local Storage على المتصفح الحالي.
- تصدير سجل الحقول إلى CSV.
- واجهة أولية لرفع صورة النبات أو فتح الكاميرا، وواجهة محادثة تجريبية.

## حدود ميزة اكتشاف الحقول

ميزة «اكتشف حقول المنطقة» لا تستخدم الذكاء الاصطناعي ولا تستنتج حدود الحقل من صور الأقمار الصناعية. هي تبحث عن عناصر الأراضي الزراعية (مثل farmland وorchard وvineyard وgreenhouse) التي سبق أن رسمها مستخدمو OpenStreetMap في مساحة الخريطة الحالية باستخدام Overpass API. قد لا تظهر نتائج في المناطق التي لم تُرسم حقولها على OpenStreetMap. عند عدم وجود نتائج، يمكن للمستخدم رسم الحدود يدويًا. راجع الحدود المقترحة قبل حفظها.

## تنبيه حول دقة البيانات

- الحقول الافتراضية وحدودها وقياساتها بيانات توضيحية.
- الحقول المضافة تحفظ محليًا على المتصفح فقط؛ لا توجد قاعدة بيانات أو مزامنة بين الأجهزة حتى الآن.
- المساحة المحسوبة تقريبية، ويجب مراجعتها بمصدر مساحي موثوق قبل استخدامها عمليًا.
- صور الأقمار الصناعية طبقة عرض جغرافي وليست تحليلًا آليًا لصحة النبات أو NDVI.
- لا توجد حاليًا قراءات حقيقية من حساسات التربة أو الطقس.
- واجهة تشخيص النبات والمساعد الذكي غير متصلتين بعد بنموذج ذكاء اصطناعي حقيقي.

## مصادر البيانات والإسناد

- بيانات OpenStreetMap متاحة وفق رخصة ODbL؛ يُعرض إسناد OpenStreetMap على طبقة الشوارع، ويجب الاحتفاظ بعبارة «© OpenStreetMap contributors» عند عرض بيانات OSM.
- خدمة Overpass API عامة ومشتركة؛ استخدمها للاستعلامات الصغيرة فقط، وتجنب الطلبات المتكررة أو المساحات الجغرافية الكبيرة.
- طبقة الصور Esri World Imagery تعرض الإسناد المطلوب من مزودها داخل الخريطة. راجع شروط Esri قبل النشر العام أو الاستخدام التجاري.

## خارطة الطريق

1. إضافة تحرير بيانات الحقل ومعلومات المحصول.
2. نقل بيانات الحقول إلى قاعدة بيانات مع حسابات مستخدمين.
3. ربط الطقس بموقع الحقل ومصدر بيانات موثوق.
4. إضافة Sentinel-2 وNDVI مع تواريخ ومصادر واضحة.
5. ربط نموذج رؤية حاسوبية لتصنيف أمراض النباتات مع درجة ثقة وحدود واضحة.
6. ربط المساعد ببيانات الحقل ومصادر زراعية موثوقة.
7. دعم قراءات الحساسات الفعلية وIoT.
8. دراسة نموذج رؤية حاسوبية لاستخراج حدود الحقول من صور جوية/فضائية، مع تقييم الدقة على بيانات محلية قبل إطلاقه.

## الملكية الفكرية

يجب مراجعة شروط استخدام كل مصدر بيانات أو خدمة خارجية قبل إطلاق التطبيق، مع الإبقاء على الإسنادات المطلوبة. لا ينبغي إعادة استخدام أكواد أو نماذج أو بيانات خارجية دون مراجعة الترخيص وتوثيق المصدر.
