# نَبْتَة | NABTA Smart Agriculture

منصة ويب عربية تجريبية للزراعة الذكية تساعد على تنظيم بيانات الحقول وعرضها على خريطة تفاعلية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## التقنيات

- Next.js App Router وTypeScript
- React وReact Leaflet وLeaflet
- OpenStreetMap لطبقة الشوارع
- Esri World Imagery لطبقة صور الأقمار الصناعية (مع إظهار الإسناد على الخريطة)
- Lucide Icons
- واجهة عربية RTL وتصميم متجاوب

## الوظائف الموجودة في النموذج

- لوحة تحكم عربية متجاوبة.
- التبديل بين صور الأقمار الصناعية وخريطة الشوارع.
- عرض الحقول التجريبية وحدودها على الخريطة.
- رسم حدود قطعة أرض بالنقر على الخريطة، ثم حفظ المضلع.
- حساب تقريبي لمساحة المضلع وتحويلها إلى فدان.
- اختيار الحقل وعرض ملخصه.
- حفظ الحقول وحدودها في Local Storage على المتصفح الحالي.
- إضافة حقل من النموذج وتصدير سجل الحقول إلى CSV.
- واجهة أولية لرفع صورة النبات أو فتح الكاميرا، وواجهة محادثة تجريبية.

## تنبيه حول دقة البيانات

- الحقول الثلاثة الأولى وحدودها وقياساتها بيانات توضيحية.
- الحقول التي يرسمها المستخدم تحفظ محليًا على المتصفح فقط؛ لا توجد قاعدة بيانات أو مزامنة بين الأجهزة حتى الآن.
- المساحة المحسوبة تقريبية، ويجب مراجعتها بمصدر مساحي موثوق قبل استخدامها عمليًا.
- طبقة الأقمار الصناعية هي صور أساس للخريطة وليست تحليلًا آليًا لصحة النبات أو NDVI.
- لا توجد حاليًا قراءات حقيقية من حساسات التربة أو الطقس.
- واجهة تشخيص النبات والمساعد الذكي غير متصلتين بعد بنموذج ذكاء اصطناعي حقيقي.

## خارطة الطريق

1. إضافة تحرير اسم المحصول ونوعه ومعلومات الحقل.
2. نقل بيانات الحقول إلى قاعدة بيانات مع حسابات مستخدمين.
3. ربط الطقس بموقع الحقل ومصدر بيانات موثوق.
4. إضافة Sentinel-2 وNDVI مع تواريخ ومصادر واضحة.
5. ربط نموذج رؤية حاسوبية لتصنيف أمراض النباتات مع درجة ثقة وحدود واضحة.
6. ربط المساعد ببيانات الحقل ومصادر زراعية موثوقة.
7. دعم قراءات الحساسات الفعلية وIoT.

## الملكية الفكرية

يجب مراجعة شروط استخدام كل مصدر بيانات أو خدمة خارجية قبل إطلاق التطبيق، مع الإبقاء على الإسنادات المطلوبة. لا ينبغي إعادة استخدام أكواد أو نماذج أو بيانات خارجية دون مراجعة الترخيص وتوثيق المصدر.
